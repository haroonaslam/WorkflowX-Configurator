## Prompt AssemblerX

1. Connect two STRING sources containing `A quiet lake` and `early morning light` to consecutive inputs on [Prompt AssemblerX](../README.md#prompt-assemblerx).
2. Keep **comma + space** selected and send **assembled_prompt** to a text display. The result is `A quiet lake, early morning light`.
3. Turn off **Prompt 2** and queue again. The output becomes `A quiet lake`. Connect **debug_info** to a second text display to see the slot states and output length.

## Quick controls

1. Connect two compatible sources, such as two STRING outputs, to **ToggleX Controller** and connect **selected** to a consumer.
2. Add **Quick ToggleX** to the main canvas. Choose a source in the controller's row and queue. Change the selection and queue again to compare the results.
3. Right-click a separate target and choose **WorkflowX: Add to Quick MuteX** or **WorkflowX: Add to Quick BypassX**. Turn its row off to apply the mode, then back on to reactivate it. [Quick controls guide](../README.md#quick-mutex-and-quick-bypassx)

For asset provisioning and additional media workflows, see [WorkflowX Downloader](../README.md#workflowx-downloader), [DetailerX, Preview, and Masks](../README.md#detailerx-preview-and-masks), [View Image (Format)](../docs/VIEW_IMAGE_FORMAT.md), and [H3 RefMod](../h3_refmod/README.md).

## Safety and portability

- No media files are bundled or embedded.
- Resource widgets contain neutral placeholders, not filenames copied from a live installation.
- API credentials are blank.
- Prompts, captions, workflow names, user names, task IDs, URLs, and output history from live workflows are not copied.
- `save_output` is disabled in the video examples until the user deliberately selects resources and an output policy.
- Live workflows were inspected read-only for realistic node combinations and execution ordering; they were never modified.

Regenerate with `python scripts/build_documentation_examples.py` or check reproducibility with `python scripts/build_documentation_examples.py --check`.
