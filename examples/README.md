# WorkflowX example workflows

These seven examples are connected teaching workflows, not node inventories. They are generated by [`scripts/build_documentation_examples.py`](../scripts/build_documentation_examples.py), load as ComfyUI workflow JSON, and collectively cover every active WorkflowX node ID.

| # | Workflow | Requirements | Status |
|---:|---|---|---|
| 1 | [Configuration and routing](01-configuration-and-routing.json) | Select local checkpoints | Model-dependent; Config SelectorX state is initialized |
| 2 | [Local generation and model management](02-local-generation-and-model-management.json) | Image, checkpoint, LoRA, FFmpeg codec | Resource/model-dependent |
| 3 | [Image loading, processing, and comparison](03-image-loading-processing-and-comparison.json) | Two local images | Locally runnable; terminal comparison is interactive |
| 4 | [Anything Swap with NanoBanana](04-anything-swap-with-nanobanana.json) | Source image and Gemini credential | API-dependent; blank credential |
| 5 | [Kie and Atlas APIs](05-kie-and-atlas-apis.json) | Optional reference image and provider credentials | API-dependent; blank credentials |
| 6 | [JsonX prompt toolchain](06-jsonx-prompt-toolchain.json) | Optional configured LLM profile | Builder/importer/randomizer local; LLM profile-dependent |
| 7 | [Advanced configured production](07-advanced-configured-production.json) | Two checkpoints, LoRAs, FFmpeg | Sanitized production pattern; model-dependent |

## Safety and portability

- No media files are bundled or embedded.
- Resource widgets contain neutral placeholders, not filenames copied from a live installation.
- API credentials are blank.
- Prompts, captions, workflow names, user names, task IDs, URLs, and output history from live workflows are not copied.
- `save_output` is disabled in the video examples until the user deliberately selects resources and an output policy.
- Live workflows were inspected read-only for realistic node combinations and execution ordering; they were never modified.

Regenerate with `python scripts/build_documentation_examples.py` or check reproducibility with `python scripts/build_documentation_examples.py --check`.
