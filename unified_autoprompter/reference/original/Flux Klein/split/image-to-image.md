## Single-reference editing

Use direct edit language. Name the target and replacement or change, then state what remains unchanged. Preserve unmentioned identity, geometry, composition, background, and light.

Compact pattern:

```text
Change the ceramic mug to matte cobalt blue; preserve its shape, handle position, table reflections, camera angle, and every other object.
```

## Multi-reference editing

Assign each image one role. Identify the base scene, then map additional images to subjects, objects, garments, styles, or backgrounds. State final placement and what incidental content must not transfer. Keep the role map short enough that each reference remains distinct.
