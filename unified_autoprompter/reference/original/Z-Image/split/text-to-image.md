# Z-Image Text to Image

## Text-to-image method

Begin with one clear sentence naming the shot, subject, and medium or style. Follow with defining subject details, supporting objects, environment, composition, lighting, and finish. Detail should sharpen the same intended image. Do not let enhancement introduce a second composition, incompatible media, or decorative content that competes with the subject.

1. Lead with subject and primary action.
2. Establish setting, layout, and camera.
3. Add medium, lighting, palette, and materials.
4. Add exact bilingual or monolingual typography.
5. Add only details that reinforce the focal image.
6. Resolve contradictions and return one prompt.
