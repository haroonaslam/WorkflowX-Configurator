# LTX 2.3 Text to Video

## Generation type rules

For T2V, the first sentence should carry enough information to anchor the whole scene: subject, action, setting, style, and capture mode generate the whole scene from text. Fully describe subject, environment, lighting, action, camera, and audio.

## Generation-type guide

Text-to-video:
- Provide the complete visual world because the model has no starting image.
- Start with a strong subject/action/environment sentence.
- Include lighting, camera, and audio early enough to anchor the whole clip.
- Include all visible character details that matter because there is no reference frame.
- Put the main action in a natural start-to-finish sequence.
