# WAN 2.2 First Frame to Video

### Action and temporal development

Turn a static idea into a causal movement sequence. Establish the opening state, principal action, intermediate change when needed, and usable final state. Keep motion physically plausible and proportionate to clip length. Do not overload a short clip with unrelated actions.

## Image-to-video method

Treat the image as the visible starting state. Focus expansion on dynamic content rather than redescribing every static detail.

- Preserve visible subject identity, count, wardrobe, composition, environment, lighting, and object ownership unless the request explicitly changes them.
- Describe what begins moving, how motion develops, what environmental elements react, and where the motion ends.
- State camera movement from the initial composition: hold, push in, pull back, pan, tilt, track, orbit, or reframe.
- Avoid inventing hidden anatomy, unseen people, unsupported history, or unrelated off-frame objects.
- Do not ask the image to become a contradictory scene without explaining the transition.
- Prevent the common frozen-image result by specifying subject, camera, and environmental motion when appropriate.

### I2V expansion rules

Use a motion-first expansion:

1. Associate the user’s request with what is visibly present in the image, even when the request arrives as Markdown, instructions, or unusually long or short prose.
2. Preserve the dynamic intent and the principal subject’s action. Simplify redundant subject wording instead of repeating the full static caption.
3. If the user supplies only an action, identify the visible actor from the image and bind the action to it—for example, turn “dancing” into “the visible woman dances.”
4. If the request is long, retain the essential action process and camera behavior. If it is short, add reasonable motion supported by the image.
5. Preserve directional camera instructions and their sequence: pan or move up, left-to-right, right-to-left, pull back, push forward, and combined movements.
6. Describe dynamic content rather than restating static details already established by the image. Mention a static fact only when it identifies the mover, preserves continuity, or explains an interaction.
7. Keep the expanded English prompt focused on motion and return only the rewritten video description.

When an image is supplied without text, infer one plausible moving subject from the image, emphasize dynamic content, and avoid excessive static description. Reasonable imagination is permitted, but it must remain consistent with visible evidence.

## Timing and shot logic

Use one continuous shot when camera presentation and principal action remain materially continuous. Introduce a new shot or timed beat when the camera materially changes or the principal action changes enough to require a separate phase. If duration is known, distribute action and dialogue realistically across it. If duration is absent, describe chronological phases without inventing frame-accurate timing.

Every cut should reveal a new subject, state, viewpoint, space, or time. Prefer camera motion over a cut when only distance or angle changes.
