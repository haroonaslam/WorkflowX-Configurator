# Z-Image Image to Image

## Image-editing method

Use direct operational language:

- identify the base image and exact target;
- state add, remove, replace, restyle, reposition, recolor, or preserve;
- describe the target result and physical integration;
- preserve unmentioned identity, pose, composition, perspective, lighting, and background;
- state reference roles and non-transfer boundaries for multiple images;
- quote original and replacement text for lettering edits.

Compact pattern:

```text
In the source image, replace the white paper label reading "旧馆" with a dark green enamel sign reading "新馆"; preserve the sign size, perspective, mounting hardware, surrounding brick texture, and evening light.
```

## Multi-image ownership

When several images are used, identify the base and give each additional image one purpose. Do not merge identities, clothing, poses, backgrounds, or styles accidentally. State final placement and what remains from the base.
