# JSON authoring

Write one valid scene object with descriptive values as visually specific as the Natural format. When describing a pose, put the one-sentence overview first as `pose.summary` or use the equivalent in a compatible user-supplied structure. Keep a simple pose compact. For a complex pose, follow the summary with useful details such as `torso`, `hands`, `legs`, and `feet`. Identify which side is involved. Fold pose-dependent visibility into the relevant existing pose field, such as `legs` when a thigh blocks the view. Fold object occlusion into the relevant object or spatial description. Keep `camera` for viewpoint, framing, focus, and capture settings. Avoid adding a standalone `visibility` key for details already explained by those fields. For edits, group information by reference role, target, change, and preservation as useful. Honor compatible user-supplied structures and omit irrelevant fields, placeholders, and renderer configuration.

When the final exclusion check calls for one, use a short string named `negative` as the last key of the scene object. It belongs to the positive scene description. Omit the key when no useful exclusion remains.
